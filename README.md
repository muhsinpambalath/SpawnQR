# SpawnQR

A fast, client-side QR code generator for creating customizable QR codes without an account.

## Features

- Live QR generation
- Link, text, Wi-Fi, and contact QR codes
- QR color and background customization
- Dot and eye styles
- Gradient support
- Emoji and image center content
- PNG and SVG downloads
- No login required
- Fully client-side QR generation

## Tech Stack

- React
- Vite
- JavaScript
- CSS
- QRCodeStyling

## Privacy

QR generation happens directly in the browser. SpawnQR does not require an account or a backend to generate QR codes.

## AI-Assisted Development

SpawnQR was developed with AI-assisted programming, which was used to help write and refine code. Product decisions, implementation, testing, debugging, and iteration were carried out as part of the development process.
